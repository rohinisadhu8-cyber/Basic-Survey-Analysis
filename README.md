# Basic Survey Analysis

## Project Overview
This project focuses on analyzing survey responses using Microsoft Excel. It helps understand customer satisfaction, gender distribution, and product preferences through categorical data analysis.

## Objectives
- Analyze survey responses.
- Clean and organize survey data.
- Calculate response counts and percentages.
- Create charts and visualizations.
- Identify meaningful insights.

## Tools Used
- Microsoft Excel
- Data Analysis
- Data Visualization

## Project Activities
1. Data Collection
2. Data Cleaning
3. Categorical Data Analysis
4. Calculation of Percentages
5. Chart Creation
6. Insight Generation

## Charts Created
- Customer Satisfaction – Column Chart
- Gender Distribution – Pie Chart
- Product Preferences – Bar Chart

## Key Insights
- Identified customer satisfaction levels.
- Analyzed gender distribution among respondents.
- Compared product preferences.

## Conclusion
This project provided practical experience in survey data analysis using Microsoft Excel. It improved my understanding of data cleaning, categorical analysis, visualization, and insight generation.
